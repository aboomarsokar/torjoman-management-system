# دليل سيناريوهات التجريب — ترجمان القرآني

> سيناريوهات شاملة لكل دور. الكلمة الافتراضية للجميع: كلمة المرور الافتراضية الموحّدة (في `app/constants/auth.ts`). ⚠️ هذا الدليل لما قبل الإصدار الثاني (حسابات البريد والأدوار الأربعة) ويحتاج إعادة كتابة.
> لبذر بيانات تجريبية جاهزة: `node --env-file=.env scripts/seed-users.mjs` ثم `node --env-file=.env scripts/seed-data.mjs`.

## الحسابات
| الدور | الحساب |
|---|---|
| مدير | `test1@test.com` |
| جودة | `test2@test.com` · `test3@test.com` |
| مشرف | `test4@test.com` … `test7@test.com` |
| معلّم | `test8@test.com` … `test20@test.com` |

> بعد تشغيل `seed-data.mjs`: تُسند حلقات للمعلّمين test8/test9/test10 ومشرفهم test4، ويُربط المشرفون بمشرف الجودة test2، وتُضاف طلاب + خطة اختبارات + تخصيص حوافز.

---

## 🟦 1 — المدير (`test1@test.com`)
1. **الدخول والملف الشخصي:** بانر «كلمتك الافتراضية» + جرّب «تغيير كلمة المرور».
2. **الإعدادات:** عدّل الهدف/النقاط/أيام الدوام/علامة الاجتياز.
3. **الحلقات:** «إنشاء حلقة» + إسناد معلّم ومشرف · «تفاصيل».
4. **الطلاب:** «إضافة طالب» بأجزاء وتاريخ التحاق مختلفة.
5. **خطة الاختبارات:** تأكّد من المحطات (من–إلى + نوع).
6. **إدارة المستخدمين:** عرض البيانات · تعطيل/تفعيل · إعادة تعيين الكلمة.
7. **الأخبار:** خبر جديد + رفع صورة + نشر → يظهر على الصفحة الرئيسية.
8. **المالية:** حركة وارد/صادر (تصدير Excel) · رواتب (اعتماد + ترحيل) · تخصيص حوافز (اعتماد).
9. **المحاضر:** محضر + اختيار الحاضرين + قراءة.
10. **التنبيهات:** إصدار تنبيه لمعلّم.
11. **دليل المؤشرات:** مراجعة المعادلات والأمثلة.

## 🟩 2 — المعلّم (`test8@test.com`)
1. **لوحة «حلقتي»:** الحلقة + الطلاب (الأجزاء + المحطة القادمة).
2. **ملف الطالب:** الرحلة + مؤشّر التقدّم الزمني.
3. **التقرير الشهري:** تعبئة → درجات محسوبة + بطاقة الإنجاز → إرسال → تصدير Excel.
4. **ترشيح للاختبار:** ترشيح طالب مستحقّ → إرسال (لا تكرار/لا اجتياز مكرّر).
5. **كشف الحوافز:** المبلغ المخصّص (قراءة) + بنود + المتبقّي → إرسال.
6. **الجرس:** التنبيه الجديد → «تأكيد الاطّلاع».

## 🟧 3 — المشرف (`test4@test.com`)
1. **اللوحة:** حلقاتي + زياراتي القادمة + عدّاد الرصد.
2. **الزيارات:** جدولة → تنفيذ (نقاط قوة/تحسين/تقييم).
3. **رصد الاختبار:** الطابور → رصد 10 خانات → يظهر في رحلة الطالب.
4. **الحلقات:** اطّلاع فقط (بلا تعديل).

## 🟪 4 — الجودة (`test2@test.com`)
1. **اللوحة:** مشرفوني + الحلقات + تقارير بانتظار الاعتماد.
2. **التقارير:** لوحة التكريم + بطاقات الإنجاز + فتح تقرير.
3. **التنبيهات:** إصدار تنبيه.

## 🟫 5 — رابط الطالب العام
- من ملف الطالب «نسخ الرابط» → افتحه بنافذة خفية → عرض الرحلة للقراءة (بلا بيانات حسّاسة) · «إعادة توليد» يُبطل القديم.

## 🔄 6 — تكامل شامل
مدير (تهيئة) → معلّم (تقرير + ترشيح + كشف) → مشرف (رصد + زيارة) → مدير/جودة (اعتماد التقرير) → تمتلئ لوحة التكريم + صفحات الحفظ + التقدّم الزمني → مدير (الكشوف الواردة → «تمّ الاطّلاع»).

## ملاحظات/فجوات معروفة
- ربط المشرف بمشرف الجودة (`quality_supervisor_id`) يُضبط حاليّاً عبر `seed-data.mjs` أو القاعدة — لا واجهة له بعد (§4.5).
- بطاقات (أ) تحميل عند الطلب و(ب) تمرير لانهائي للقوائم (§4.16) — مؤجّلة.
- اختبارات Vitest/Playwright — مؤجّلة.
